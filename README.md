# web-mobile
Arquivos escritos na matéria Desenvolvimento Web e Mobile

Baixe NVM para instalar e usar node 24. Na IDE, altere as config para usar node 24.  
Depois, dê **npm install** e **npx prisma generate**. Roda com **npm run start:dev**. Porta 3000.  
Para ver os dados do Banco, rode **npx prisma studio**. Porta 51212.
